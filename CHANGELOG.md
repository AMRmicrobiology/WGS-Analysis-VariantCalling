## [2.0.0] – 2025-13-11
### Added
- Stable release of the WGS-Analysis-VariantCalling pipeline.
- Full processing workflow for Illumina WGS data.
- Assembly and reference-based modes.
- Annotation workflow with merged databases.
- Extended WGS analysis modules (multi-step pipeline).
- Docker container for fully reproducible execution.

### Changed
- Updated main workflow with improved QUAST integration.
- Updated assembly mode with enhanced stability and consistency.

### Fixed
- BUSCO WGS module issues.
- MRSA analysis module refinements.
